# QUIZORA

المشروع مرتب إلى `backend/` و`frontend/` و`docs/`. ملفات البيانات والسكربتات والاختبارات الخاصة بالخلفية موجودة داخل `backend/`.

- تسجيل الدخول والموقع المنشور متاحان من الهاتف والكمبيوتر عبر الخلفية المشتركة على Railway؛ لا يلزم تشغيل Termux أو ngrok لاستخدامهما.
- التشغيل المحلي الاختياري: على الهاتف استخدم `bash setup.sh` ثم `bash run.sh`؛ وعلى Windows استخدم `START_QUIZORA.bat` و`STOP_QUIZORA.bat`. يتطلب تشغيل الخلفية المحلية إعداد `.env` محليًا.
- لوحة الإدارة متاحة من الواجهة عند `/admin.html`؛ تتطلب حساب مدير محفوظًا في PostgreSQL.
- شرح وظيفة الملفات والتشغيل: [docs/README.md](docs/README.md).
- خطوات نشر `backend/` و`frontend/` على استضافتين منفصلتين موضحة في الدليل.
- دليل Termux المختصر: [docs/اقرأني_طريقة_التشغيل.txt](docs/اقرأني_طريقة_التشغيل.txt).
