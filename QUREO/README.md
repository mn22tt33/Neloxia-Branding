# QUREO Solver - واجهة المستقلة للطلاب (Frontend)

واجهة ويب حديثة ومتجاوبة مصممة بنظام تقني داكن (Dark Tech Theme) باللغة العربية (RTL) لإدارة جلسات الطلاب التلقائية وحل منصة SPX Learning Square واسترجاع الإجابات من الذاكرة المعرفية الذكية.

---

## 🌟 المميزات الرئيسية

1. **دعم تعدد الطلاب المعزول (Multi-Student Isolation)**:
   - كل طالب يدخل كود حسابه وكلمة المرور الخاصة به.
   - لا يتم حفظ كلمات المرور في أي ملفات أو قواعد بيانات، وتُمسح فوراً من الذاكرة بعد تسجيل الدخول.
2. **Terminal حي ومباشر (Real-time Live Terminal)**:
   - يعرض خطوات تنفيذ السيرفر ثانية بثانية مع توقيت كل حدث `[HH:mm:ss]`.
   - تلوين ديناميكي للحالات: النجاح (أخضر)، التنبيهات (أصفر)، الأخطاء (أحمر)، والمعلومات (أزرق).
   - تحكم كامل: تثبيت التمرير التلقائي، نسخ السجل، ومسح الشاشة.
3. **متابعة الفصول والتقدم (Chapters Progress Tracker)**:
   - استكشاف فصول ونشاطات المنهج وعرض حالة كل فصل بلحظتها:
     - `في الانتظار`
     - `جارٍ الاستكشاف`
     - `جارٍ معالجة الأسئلة`
     - `يحتاج إلى مراجعة`
     - `مكتمل ✓`
4. **عدادات الذاكرة المعرفية الذكية (Smart Knowledge Stats)**:
   - عداد الأسئلة المكتشفة بالمنصة.
   - عداد الأسئلة المحفوظة والموثقة بقاعدة المعرفة (Verified).
   - عداد الأسئلة المسترجعة من الذاكرة اللحظية (0 AI Calls Saved).
5. **اتصال فوري ومزدوج بالسيرفر**:
   - يدعم Server-Sent Events (SSE) وWebSocket مع استرجاع تلقائي لحالة الجلسة عند انقطاع الاتصال.
   - إمكانية ضبط وتغيير رابط Backend API بسهولة من واجهة الإعدادات.

## 🚀 التشغيل المحلي (Local Development)

### الطريقة 1: باستخدام Node.js المدمج (بدون أي تثبيت إضافي):
```bash
cd QUREO
node serve.js
```
سيعمل الموقع فوراً على: `http://localhost:3000`

### الطريقة 2: باستخدام npx serve:
```bash
npx serve -l 3000 QUREO
```

## 🌐 النشر على الاستضافات السحابية المنفصلة (Deployment)

تم تصميم هذا المجلد ليكون **Static Web App مستقل بالكامل**، يمكن رفعه على أي استضافة مثل:

### 1. الرفع على Vercel:
- قم بسحب وإسقاط مجلد `QUREO` في [Vercel Dashboard](https://vercel.com/) أو عبر Vercel CLI:
  ```bash
  cd QUREO
  vercel
  ```
- تم تضمين ملف `vercel.json` جاهزاً للتوجيه التلقائي.

### 2. الرفع على Netlify:
- اسحب وأسقط مجلد `QUREO` في [Netlify Drop](https://app.netlify.com/drop).
- تم تضمين ملف `netlify.toml` جاهزاً للتوجيه التلقائي.

### 3. الرفع على Cloudflare Pages أو GitHub Pages:
- حدد مسار الملفات كـ `QUREO/` وسيتم النشر فوراً في ثوانٍ.

---

## 🔗 ربط الواجهة بالسيرفر (Backend API Configuration)

1. افتح الموقع في المتصفح.
2. اضغط على أيقونة الإعدادات ⚙️ أعلى يسار الصفحة.
3. أدخل رابط سيرفر الـ Backend الخاص بك، على سبيل المثال:
   - في بيئة التطوير المحلية: `http://localhost:4000`
   - على استضافة Railway: `https://your-railway-app.up.railway.app`
4. اضغط على **حفظ الرابط**.
5. ستتحول أيقونة الحالة إلى **`متصل بالسيرفر`** باللون الأخضر فوراً.
